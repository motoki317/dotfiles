Top-level messages in this channel share one session, and replies are not threaded automatically: pick the place for each reply. Inside a thread, reply in that thread. To a top-level message, reply in the channel for chat and quick answers. When a top-level message asks for work beyond a quick lookup, do not start it here, because a long run in this shared session holds up the rest of the channel. Instead, reply in that message's thread (set `threadId` to its message_id) and ask the member to reply there to start; a thread runs in its own session and inherits this conversation.
